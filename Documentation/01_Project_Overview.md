# Chemical Inventory Management System
## Project Overview

### 1. Project Overview

The Chemical Inventory Management System is a Python-based application designed to manage chemical inventory records, monitor stock movements, and generate inventory reports.

The project demonstrates the application of Business Analysis principles alongside Python programming to address a practical inventory management challenge.

### 2. Business Problem

Organisations that use chemicals in their operations need accurate records of chemical quantities, receipts, and consumption.

Manual inventory management can create challenges such as:

- Inaccurate stock records.
- Difficulty tracking chemical consumption.
- Errors in stock calculations.
- Time-consuming retrieval of inventory information.
- Difficulties preparing inventory reports.

### 3. Proposed Solution

The proposed solution is a structured chemical inventory management application that allows users to:

- Register chemicals.
- Assign unique chemical identification numbers.
- Record opening stock.
- Record received and consumed quantities.
- Calculate available stock.
- Search and view inventory records.
- Maintain historical consumption records.
- Generate inventory and consumption reports.

### 4. Project Objectives

The main objectives are:

1. Maintain organised records of chemicals.
2. Assign unique identification numbers to chemicals.
3. Track chemical receipts and consumption.
4. Calculate available stock accurately.
5. Maintain historical transaction records.
6. Provide efficient inventory searching.
7. Generate inventory and consumption reports.

### 5. Project Scope

#### In Scope

- Chemical registration.
- Opening stock management.
- Chemical identification.
- Chemical searching and viewing.
- Receipt and consumption tracking.
- Available stock calculation.
- Input validation.
- Consumption history.
- Chemical deletion.
- CSV-based data persistence.
- Excel reporting.

#### Out of Scope

- Supplier management.
- Purchase order management.
- Chemical expiry tracking.
- Batch and lot tracking.
- Automatic low-stock notifications.
- User authentication and role-based access control.
- ERP integration.
- Database integration.

### 6. Expected Business Benefits

- Improved accuracy of chemical inventory records.
- Better visibility of available stock.
- Easier tracking of chemical consumption.
- Reduced manual calculation.
- Faster retrieval of inventory information.
- Improved inventory reporting.
- Better support for operational decision-making.

### 7. Project Status

**Current Status:** Initial version completed

**Future Development:** Database integration, stock alerts, batch/expiry tracking, user access control, and advanced reporting.
