# Chemical Inventory Management System
## Stakeholder Analysis

### 1. Purpose

Stakeholder analysis identifies the individuals or groups who interact with the system, are affected by the system, or have an interest in its outcomes.

Understanding stakeholder needs helps ensure that the proposed solution addresses actual business requirements.

### 2. Stakeholder Identification

| Stakeholder | Role | Primary Interest |
|---|---|---|
| Storekeeper / Inventory Officer | Maintains chemical inventory | Accurate stock records and efficient inventory management |
| Production / Operations Officer | Uses chemicals during operations | Visibility of available chemical stock and consumption |
| Department Manager | Oversees inventory and operations | Inventory visibility, consumption information, and reporting |
| System Administrator / Developer | Maintains the application | System reliability, data integrity, and maintainability |

### 3. Stakeholder Needs

#### Storekeeper / Inventory Officer

The Storekeeper or Inventory Officer needs to:

- Register new chemicals.
- Record opening stock.
- Record received quantities.
- Record consumed quantities.
- Search and view inventory records.
- Maintain accurate stock information.
- Review historical consumption.
- Generate inventory reports.

#### Production / Operations Officer

The Production or Operations Officer needs to:

- Check the availability of chemicals.
- Review chemical consumption information.
- Obtain reliable inventory information for operational planning.

#### Department Manager

The Department Manager needs to:

- Review inventory levels.
- Monitor chemical consumption.
- Review inventory and consumption reports.
- Use inventory information to support operational decisions.

#### System Administrator / Developer

The System Administrator or Developer needs to:

- Maintain reliable application functionality.
- Ensure data is stored correctly.
- Maintain and modify the application when required.
- Troubleshoot system issues.

### 4. Stakeholder Expectations

| Stakeholder | Key Expectation |
|---|---|
| Storekeeper / Inventory Officer | Easy and accurate inventory management |
| Production / Operations Officer | Reliable information about chemical availability |
| Department Manager | Clear inventory and consumption information |
| System Administrator / Developer | Reliable, maintainable, and consistent application |

### 5. Stakeholder Considerations

The current application does not implement separate user accounts or role-based access control.

Therefore, the stakeholder roles described above represent the **business roles and intended users**, rather than separate technical user permissions within the current application.

Role-based access control can be considered as a future enhancement.
